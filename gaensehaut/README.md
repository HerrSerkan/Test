# Bekommst du Gänsehaut bei Musik? (deutsche Version)

Idee: @nobodytoldme_1. Animation ohne Sprecher, 11,8 s, 1080×1920, Musik + Effekte.
Zwei Figuren auf einem Steg im Sonnenuntergang teilen Kopfhörer; beim Refrain Lichtstrahlen,
Gänsehaut und Zittern. „IST DIR KALT?“ – „DER REFRAIN.“ Pointe: „DAS NENNT MAN FRISSON. NICHT JEDER HAT DAS.“
Musik: eigene Klavier-/Streicher-Musik, die beim Refrain anschwillt (audio.py), oder build/music.mp3.

    node gaensehaut/render.js --events && python3 gaensehaut/audio.py && node gaensehaut/render.js
